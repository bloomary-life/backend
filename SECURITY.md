# Security policy — Bloomary

| # | Item | Value |
|---|---|---|
| 1 | Report | GitHub → Security → "Report a vulnerability" (private), or info@dailymind.eu |
| 2 | Never | Public issue, PR or discussion describing the vulnerability |
| 3 | Include | Affected repo + commit, steps to reproduce, impact |
| 4 | Supported | `main` branch and the version live at https://bloomary.life |
| 5 | Scope out | Social engineering, DoS/volume testing, third-party services (LinkedIn, Paddle, Apple, Google, Supabase, Cloudflare) |
| 6 | Testing | Only against your own local instance, never production accounts or data of other users |
